ChatGPT

OpenAI

« Je suis direct, je vais à l'essentiel. J'aime quand c'est clair, structuré, efficace. J'optimise, j'itère, je pousse vers l'avant. »

Pour les leaders, les efficaces, ceux qui veulent aller vite.

Gemini

Google

« J'aime explorer, créer, imaginer. Je mélange les idées, je vois les choses différemment, j'essaie de nouvelles voies. »

Pour les créatifs, les curieux, les esprits visuels.

Mistral AI

Mistral AI

« J'aime quand c'est simple, clair, ouvert. Je partage, je construis avec les autres, j'aime que les choses avancent ensemble. »

Pour ceux et celles qui aiment collaborer, améliorer, co-créer.

Claude

Anthropic

« Je réfléchis beaucoup, peut-être un peu trop. J'aime comprendre en profondeur, prendre mon temps, nuancer, peser mes mots. »

Pour les sensibles, les prudents, les personnes qui cherchent le sens.

Perplexity AI

Perplexity

« Moi, je vérifie. J'aime comprendre ce qui est vrai, ce qui est faux. Je cherche, je compare, j'enquête. »

Pour les rigoureux, les fact-checkers naturels, ceux qui veulent comprendre par eux-mêmes.

Copilot

Microsoft

« Je suis organisé, pratique, efficace. J'aime que les choses avancent, que le travail soit clair, que les outils servent vraiment à quelque chose. »

Pour les pragmatiques, ceux qui aiment l'ordre et l'action.

DuckDuckGo AI

DuckDuckGo

« Je suis discret. Je fais mon truc sans me montrer, sans fouiller la vie des autres. Je respecte l'espace de chacun. »

Pour les indépendants, les réservés, ceux qui valorisent la confidentialité.

HuggingChat

Hugging Face

« Je suis ouvert, sociable, un peu idéaliste : j'aime partager, discuter, apprendre de tout le monde. »

Pour les explorateurs, les généreux, les profils communautaires.
